ПЕРЕД УСТАНОВКОЙ

Коротко о важном.

Это официальный клиент Telegram Messenger Inc.?

Нет. Это независимая оболочка от German-GPD. Внутри загружается официальный сайт web.telegram.org/a/. Проект не связан с Telegram Messenger Inc..

Нужен ли Microsoft Edge?

Нужен Microsoft Edge WebView2 Runtime. Он может быть установлен отдельно от браузера Edge. Установщик проверяет его наличие и при необходимости предложит открыть официальную страницу загрузки.

Где хранятся данные входа?

Локально, в профиле WebView2 в папке %LOCALAPPDATA%\GermanGPD\Telegram\WebView2. Не передавай эту папку другим людям.

Приложение бесплатное?

Да. Исходный код распространяется по лицензии MIT. Для использования Telegram действуют условия и ограничения самого сервиса Telegram Messenger Inc..
