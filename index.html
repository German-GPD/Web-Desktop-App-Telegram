ПРОСТО И ПОНЯТНО

Telegram, который
живёт на рабочем столе.

Небольшая Windows-оболочка вокруг официального Telegram Web. Мы не меняем сам сервис и не создаём альтернативный мессенджер.

Привычный Telegram Web

Приложение загружает официальный веб-клиент Telegram. Вход выполняется непосредственно на сайте Telegram.

↻

Сессия сохраняется

Отдельный профиль WebView2 хранит локальные данные сайта между запусками.

Быстрая навигация

F5 или Ctrl + R — обновить. Alt + ← / Alt + → — назад и вперёд.

⇩

Загрузки и разрешения

Обработка загрузок и запросов доступа к камере и микрофону через WebView2.

Настройки внешнего вида

Светлая, тёмная и системная темы, масштаб сайта и настройка верхней панели.

Нативная технология

C# · .NET 8 · WPF · Microsoft Edge WebView2. Без Electron.

ПЕРЕД УСТАНОВКОЙ

Коротко о важном.

Это официальный Telegram Desktop?

Нет. Это независимое приложение German-GPD, которое открывает официальный Telegram Web в отдельном окне Windows. Оно не связано с Telegram Messenger Inc.

Где хранится авторизация?

В локальном профиле WebView2: %LOCALAPPDATA%\GermanGPD\Telegram\WebView2. Не передавай эту папку другим людям: в ней могут находиться данные активной сессии.

Нужен ли установленный Microsoft Edge?

Нужен Microsoft Edge WebView2 Runtime. Это отдельный компонент, он может быть установлен даже без браузера Edge. Установщик проверяет его наличие и предлагает открыть официальную страницу Microsoft, если runtime отсутствует.

Можно ли использовать приложение бесплатно?

Да. Исходный код распространяется по лицензии MIT. Использование самого Telegram регулируется условиями Telegram.

Что входит в установщик?

Приложение для Windows x64, ярлык в меню «Пуск» и необязательный ярлык на рабочем столе. Установка выполняется в профиль пользователя без прав администратора.
